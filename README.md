# Halloween Mágico — Página de Vendas

Landing page de vendas para um kit de atividades infantis de Halloween (livro de atividades, jogos e desafios, recorte e monte). Feita em HTML, CSS e JavaScript puro, com foco em dispositivos móveis e layout dedicado para desktop.

## Recursos

- Design responsivo (mobile-first) com versão para computador
- Tema roxo e laranja com molduras decorativas de Halloween
- Abas interativas de produtos, galeria com lightbox e FAQ sanfona
- Contador regressivo de oferta e barra de compra fixa
- Imagens otimizadas para carregamento rápido

## Estrutura

```
index.html      → página
styles.css      → estilos
script.js       → interações
assets/         → imagens
```

## Como abrir

Abra o arquivo `index.html` em qualquer navegador. Não precisa instalar nada.

## Personalização

- Link de compra: no `script.js`, altere a constante `CHECKOUT_URL` para o endereço do seu checkout.
- Textos e preços: edite diretamente no `index.html`.
